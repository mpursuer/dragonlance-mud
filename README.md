# 龙枪MUD

照着《龙枪》十三卷故事改编的浏览器单人文字冒险：穿越到克莱恩，带着一块来历不明的混沌宝石，和英雄们一起走完龙枪战争。

**在线游玩：<https://mpursuer.github.io/dragonlance-mud/>**

- 免费，不用安装，电脑和手机的浏览器都能玩。
- 存档保存在你自己的浏览器里，可以在“设置”里导出、导入。
- 这里只放打包好的网页（`index.html`）和插图、肖像；游戏的源代码不在这个仓库里。
